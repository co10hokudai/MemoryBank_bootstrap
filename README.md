# Memory Bank Bootstrap

複数のAIエージェントで同じプロジェクトの記憶を参照・更新するための初回導入指示書です。記憶は作業フォルダの `_MemoryBank/` にMarkdownとして保存します。

## 使い方

1. [_MEMORY_BANK_BOOTSTRAP.md](_MEMORY_BANK_BOOTSTRAP.md) をダウンロードします。
2. 記憶管理を導入したい作業フォルダをAIエージェントで開きます。
3. 指示書を渡して、次のように依頼します。

   > この指示書を実行し、現在の環境にMemory Bankをセットアップしてください。

導入後は、同じ作業フォルダを開いて作業を続けます。共通の入口 `AGENTS.md` と `_MemoryBank/PROTOCOL.md` が記憶の参照・更新方法を案内します。

## 作成される記憶

`_MemoryBank/` に運用規則 `PROTOCOL.md` と、次の基本6ファイルを整備します。

- `projectBrief.md`: 目的・範囲・要件
- `productContext.md`: 背景・利用者・期待する成果
- `activeContext.md`: 現在の状況・次の作業
- `systemPatterns.md`: 構成・判断理由・作業方法
- `techContext.md`: 環境・制約・資料の所在
- `progress.md`: 完了・未完了・検証結果

既存の指示・記憶がある場合は、それらを保持して統合します。旧名 `memory-bank/` からの移行方法も指示書に含まれています。

## 利用できる環境と制約

ファイルを読み書きできるAIエージェントでの利用を想定しています。製品・バージョンによって指示の読み込み方法が異なるため、導入結果を確認してください。新規セッションや別AIでの自動読み込みは、実際に試すまで保証されません。

読み取り専用の環境では、利用者によるファイル保存や設定が必要な場合があります。引き継げるのは記録した情報であり、保存していない会話の細部は復元できません。

秘密情報や不要な個人情報を記憶に保存しないでください。記憶をGitで追跡する場合は、その公開範囲も確認してください。

この指示書はCline Memory Bankの基本6ファイル構成と更新思想を参考にした独立した派生設計です。参考資料は指示書末尾に記載しています。
